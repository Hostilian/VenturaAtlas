# EUshop Playwright E2E Critical Journey Skill

## Overview

This skill establishes automated Playwright E2E testing patterns for buyer checkout, seller onboarding, trader identity audit, and dispute resolution.

---

## 1. Mandatory Critical Test Journeys

- **Buyer Checkout Journey**: Browse catalog -> allergen filter -> add to cart -> server checkout -> order confirmation.
- **Seller KYBC Journey**: Become seller -> enter VAT / business identity -> self-certify compliance -> verify listing gate.
- **Trader Traceability**: Verify "Sold by [Seller Name]" UI element renders persistently on food product pages.
