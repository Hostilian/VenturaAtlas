# EUshop YC Investor Diligence Package Skill

## Overview

This skill provides investor data room readiness standards, unit economics calculations, and metric truthfulness rules for EUshop.

---

## 1. Unit Economics & Metric Labeling

- **GMV**: Gross Merchandise Value from verified fulfilled orders (`Order.OrderStatus.DELIVERED`).
- **Take Rate**: Platform commission rate percentage.
- **Contribution Margin**: Revenue minus payment processing fees, shipping, and fulfillment costs.
- **Truth Labeling**: All metrics presented in pitch materials or documentation MUST be explicitly labeled as `[MEASURED]`, `[TEST_DATA]`, or `[TARGET]`. Never state test data as active production traction.
