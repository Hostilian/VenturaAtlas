# Venture Atlas OS — Root Multi-Agent Orchestration Guidelines

This file defines the primary orchestration rules, agent roster, file ownership boundaries, and provider policies for AI coding agents operating in this workspace (Google Antigravity 2.0, Cursor, Claude Code, etc.).

---

## 1. Core Principles

1. **Evidence-First Authority**: Never invent or fabricate market demand metrics, scores, or citation sources.
2. **Single Source of Truth**:
   - `data/ideas.json`: Canonical ideas (185 records)
   - `data/idea-staging-queue.json`: Staged candidates (173 records)
   - `data/categories.json`: Categories (82 records)
   - `data/sources.json`: Cited sources (62 records)
   - `data/repository-meta.json`: Single source of truth for counts and metrics.
3. **No Direct `_site/` Editing**: `_site/` is a build artifact generated by `npm run build:site` or `npm run build:verified`.
4. **Git Worktree Isolation**: Autonomous agent tasks must run in isolated Git worktrees (`feat/va-<role>-<taskid>`).

## 3. Verification Protocol

Before completing any task, run the standard quality verification pipeline:
```bash
npm run quality
```
Ensure that all unit tests, schema validations, consistency checks, drift checks, constitution verification, and PWA contract tests pass with zero errors.
