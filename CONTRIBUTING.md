# Contributing

1. Do not add secrets, personal data, or copyrighted full-text sources without permission.
2. Preserve original wording and provenance in the extraction ledger.
3. Do not merge materially distinct ideas merely because their names overlap.
4. Label facts, claims, assumptions, estimates, and unknowns.
5. Add contradictory evidence and a falsification test.
6. Install dependencies with `npm ci` and `python -m pip install --disable-pip-version-check -r services/ventureatlas-worker/requirements.txt`.
7. Run `npm test`, `npm run validate`, and `npm run check-links`.
