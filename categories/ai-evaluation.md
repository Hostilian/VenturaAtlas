# AI evaluation

5 ideas.

- [AgentLingo — Multilingual AI Agent Launch Gate](../ideas/agentlingo-multilingual-ai-agent-launch-gate.md) — Native-language release tests and reusable regression packs for customer-facing voice and chat agents.
- [RAG Citation Fidelity Gate](../ideas/rag-citation-fidelity-gate.md) — Tests whether cited answers are actually supported at the strength and location claimed.
- [Model & Prompt Regression Gate](../ideas/model-and-prompt-regression-gate.md) — Blocks model, prompt, tool, or provider changes that violate a defined production contract.
- [PSTN Accent & Noise Regression Suite](../ideas/pstn-accent-and-noise-regression-suite.md) — Tests voice agents through realistic codecs, accents, noise, interruptions, and correction patterns.
- [Policy-Journey Adherence Pack](../ideas/policy-journey-adherence-pack.md) — Tests multi-step support-agent journeys, tool actions, escalation, and refusal boundaries.
