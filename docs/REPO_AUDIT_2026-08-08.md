## 1. Actual Architecture Map

VenturaAtlas OS operates as a decoupled two-plane system:

1. **Static Presentation Plane (GitHub Pages / PWA):**
   - High-performance, dependency-light static web app served from `index.html` and `docs/`.
   - Client-side interactivity via `assets/js/site.js` and `assets/js/home.js`.
   - Offline support via Service Worker (`sw.js`) and PWA Manifest (`manifest.webmanifest`).
   - Production artifact built dynamically into `_site/` by `scripts/build-public-artifact.js`.

2. **Control Plane & Autonomous Worker Engine:**
   - Multi-provider orchestration in `scripts/va_orchestrator.py` with modular runtime components in `scripts/va_runtime/`.
   - Autonomous parallel idea generation in `scripts/autonomous-idea-generator.py`.
   - Unattended GCP Cloud Run entrypoint in `cloud-control-plane/job_runner.py` with Terraform infra definitions in `cloud-control-plane/terraform/`.
   - Specialized subproduct FactBounty in `apps/factbounty/` (Express, TypeScript, SQLite).

## 7. Strategic Product & Research Quality Gaps

1. **Information Architecture (IA):** Navigation presents library items rather than founder decision flows (**DISCOVER** → **EVALUATE** → **BUILD**).
2. **Matcher Engine:** Currently shallow; needs multi-dimensional Founder Constraint & Fit Engine (resources, skills, distribution, preferences, risk).
3. **Rankings & Sensitivity:** Rankings lack multi-lens toggle and score sensitivity analysis (robustness vs. fragile rankings).
4. **Opportunity Economics:** Calculator is currently FactBounty-centric; needs universal idea economics lab with conservative/base/upside scenarios.
5. **Evidence & Provenance:** Claims in dossiers lack explicit Tier A/B/C/D source classification, recency tracking, and disconfirming research passes.
6. **Agent Roster:** `.agents/AGENTS.md` is currently FactBounty-centric. Needs refactoring into VenturaAtlas domain specialists.
7. **Autonomous Runtime:** Needs worktree isolation manager (`scripts/va_runtime/orchestration/worktrees.py`) and bounded execution arguments (`--once`, `--max-cost`, `--max-concurrency`).
