Local-private boundary · workspace contract 1.1.0. Chessboard starts empty, reads only a JSON file you explicitly import, and stores the validated workspace in this browser. It does not fetch private strategy, publish an imported workspace, contact market actors, or run background work. Exports are unencrypted private JSON and must be handled as private strategy data.

Authority and interpretation boundary

Chessboard cannot select an active venture or change canonical scores, rankings, or lifecycle state. When repository authority records no authoritative active venture, every imported analysis target, strategic brief, position, and stress result remains provisional dogfood—even when its workspace validates successfully.

What a validated 1.1.0 workspace can show
  • Strategic briefs, alternative market boundaries, value-chain layers, ecosystem actors, typed relationships, and structural position comparisons.
  • Provider power, switching processes, multi-homing constraints, substitutes, complementors, regulators, standards bodies, and control points.
  • Actor-focused response paths with evidence, counterevidence, falsifiers, attack/countermove trees, typed strategic stresses, and explicit survival outcomes.
  • Moats, anti-moats, commoditization risks, dated events with affected references, contradictions, research gaps, handoffs, and source trace cards.

The interface renders validated records and deterministic comparisons; it does not turn hypotheses into facts or authorize external action. See the public workspace schema for the complete contract.
