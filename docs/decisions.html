How Decisions Are Made

📋

1. Proposal

Open a GitHub Issue with the proposed decision and evidence

🔍

2. Evidence Review

7-day window for evidence submissions and documented objections

🗳️

3. Pairwise Vote

Participants submit vote packets as signed JSON files

✅

4. Consensus

Decision recorded in data/decisions.json and committed
