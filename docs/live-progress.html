What each state means

  • Live now / fresh heartbeat: a reachable control plane supplied a recent timestamped heartbeat.
  • Cloud running / cloud verified: GitHub reports a recent scheduled workflow in progress or successfully completed. This is recurrence evidence, not a claim that every provider returned useful research.
  • Stale / degraded: the latest receipt is too old or the latest run failed. Human attention may be needed.
  • Status unknown: neither source could be reached or validated. Unknown never silently becomes green.
