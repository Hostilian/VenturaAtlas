Research Automation Status

Venture Atlas has a scheduled, bounded research workflow. Its current health must be established from a fresh runtime receipt; repository counts, page timestamps, and configured providers do not prove that a worker is running.

Historical activity cards formerly shown here contained fixed dates and unsupported runtime claims. They have been retired. Use the live status resolver for the latest available heartbeat or scheduled GitHub Actions receipt.

How to read the status

  • Live means a fresh active heartbeat was verified.
  • Verified means a recent scheduled run or healthy idle heartbeat was verified; it does not mean work is executing at this instant.
  • Stale, degraded, or unknown means continuity is not currently proven.
