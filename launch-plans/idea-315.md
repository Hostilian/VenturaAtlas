# Launch Plan — EmergencyComms Regression Cloud — NG112 & eCall Interoperability Test Suite

## Go-to-Market

- **Initial Niche:** Public Safety Answering Point (PSAP) software vendors, automotive eCall suppliers, and emergency telecom providers
- **ICP:** Public Safety Answering Point (PSAP) software vendors, automotive eCall suppliers, and emergency telecom providers
