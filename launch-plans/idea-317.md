# Launch Plan — EES Carrier Journey Monitor — EU Entry/Exit System Synthetic API & Fallback Tester

## Go-to-Market

- **Initial Niche:** International airlines, cross-channel ferry operators, international rail/coach carriers, and travel IT providers
- **ICP:** International airlines, cross-channel ferry operators, international rail/coach carriers, and travel IT providers
- **Positioning:** A specialized, fast, low-friction solution for Pre-boarding verification API failures causing port congestion and passenger boarding halts
