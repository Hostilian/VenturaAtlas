# DPP semantic model

Canonical object for the prototype:

```json
{"product_id":"urn:va:product:001","operator_id":"urn:va:operator:001","product_group":"battery","metadata":{},"passport_url":"https://example.invalid/dpp/001","schema_version":"draft"}
```

Validation concerns: identifier format, operator identity, product-group schema, required metadata, URL reachability policy, schema version, lifecycle update semantics, and proof-of-registration retention. The free Commission semantic repository is a dependency, not a moat.
