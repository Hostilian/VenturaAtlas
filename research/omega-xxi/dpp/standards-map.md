# DPP standards map

| Layer | Authority / family | Current role | Readiness |
|---|---|---|---|
| legal envelope | Regulation (EU) 2024/1781 (ESPR) | DPP requirements, backup, access, registry/service-provider powers | binding framework |
| product-group data | delegated acts under ESPR | product-specific data, carrier, retention, access | varies; not one universal frozen model |
| identifiers | standards designated/harmonised under ESPR process | product/operator/facility identifiers and data carriers | selection/finalisation varies |
| registry | European Commission DPP Registry | registers identifiers and supports verification/control functions | under implementation |
| semantic repository | Commission-managed semantic layer | common interpretation of DPP data concepts | emerging |
| provider rules | Commission delegated/implementing measures | service-provider requirements and possible certification | not final in this slice |

Compiler rule: generate only from a versioned product-group source bundle. Never imply that a generic ESPR object is a legally sufficient passport.
