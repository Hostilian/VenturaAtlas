# What PassportCompiler can automate today

## Buildable without pretending the regime is final

- ingest a pinned source bundle;
- compile a canonical model into JSON Schema and language types;
- emit forms, validators, documentation, and fixtures;
- diff versions and classify migrations;
- preserve source citations and checksums;
- reject unknown mandatory semantics;
- generate access-control and evidence-link stubs;
- package portable, signed snapshots.

## Blocked on official/product-group detail

- declaring legal completeness for a product group;
- final registry submission;
- final identifier validation;
- final service-provider certification;
- final backup/restore acceptance;
- universal retention and access rules.

This boundary is the difference between a useful compiler prototype and an unsupported compliance claim.
