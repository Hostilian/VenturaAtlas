# eFTI pre-certification SDK — kill report

Current decision: **RESEARCH/PROTOTYPE ONLY**

The wedge is attractive because certification is explicit and the legal requirements are testable. It dies if the final assessment rules arrive with a complete official/open reference suite, conformity bodies bundle equivalent tooling, or platform vendors have no reason to run continuous tests outside formal assessment.

Required survival evidence:

- 10 qualified technical interviews;
- 3 vendors run the prototype;
- 1 contributes a representative schema/fixture;
- 1 pays or prepays;
- at least one recurrent post-certification version or interoperability failure not solved by official tooling.
