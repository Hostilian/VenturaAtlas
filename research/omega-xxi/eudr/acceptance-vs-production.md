# EUDR ACCEPTANCE versus LIVE

| Property | ACCEPTANCE | LIVE |
|---|---|---|
| Purpose | training and testing | legal submission and management |
| Legal value | none | filings can have legal value |
| Officially described as replica | yes | n/a |
| Safe for synthetic fixtures | yes, subject to terms | no assumption |
| Fidelity proven | no | authoritative production system |

## Core experiment

Run the same redacted/synthetic fixtures against ACCEPTANCE and, only with an authorised operator, observe equivalent LIVE outcomes. Record differences in validation, status transitions, timing, error payloads, and schema version. Until then, `preflight_fidelity` is **unknown**.
