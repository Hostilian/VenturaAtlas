# EUDR competitor boundary

The competitive question is not “who offers EUDR?” but “who already owns reliable API participation, status reconciliation, and version maintenance?”

| Segment | Named examples | Working classification | Must verify |
|---|---|---|---|
| official utility | European Commission Information System | INFRASTRUCTURE | API scope, support, release policy |
| ERP | SAP, Oracle, Microsoft Dynamics | CUSTOMER/PARTNER/COMPETITOR unclear | native submission and maintenance depth |
| supply-chain platforms | Prewave, IntegrityNext, Achilles | COMPETITOR/PARTNER unclear | direct submission, retries, evidence replay |
| traceability/DPP providers | existing vendor corpus | ADJACENT | EUDR adapter breadth and pricing |
| consultancies | major assurance and trade firms | PARTNER/COMPETITOR | managed operation vs software |

No whitespace claim is valid until feature-by-feature documentation, pricing, customer references, and failure-handling behavior are captured.
