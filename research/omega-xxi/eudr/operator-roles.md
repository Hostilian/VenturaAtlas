# EUDR operator roles

The official Information System is used by operators, traders, and representatives. The July 2026 implementation update also distinguishes large/medium operators, micro/small operators already covered by the EU Timber Regulation, other micro/small operators, and micro/small primary operators using simplified declarations.

## Role questions for protocol forensics

| Role dimension | Question |
|---|---|
| operator | Which API operations and declarations may it perform? |
| trader | Which obligations and references differ by size and supply-chain position? |
| authorised representative | How is delegation created, scoped, revoked, and evidenced? |
| upstream/downstream | Which reference reuse and information duties differ? |
| micro/small primary operator | Which simplified-declaration operation/schema applies? |
| API technical principal | How is it bound to a legal actor? |

Do not collapse legal role, organisation size, supply-chain position, and technical credential into one `role` field.
