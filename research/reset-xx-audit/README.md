# RESET XX adversarial audit — 21 August 2026

Decision: **reject the fresh-slate leaderboard as a novelty result. Preserve the Public Infrastructure Edge heuristic and merge the two useful experiments into existing ideas.**

## Bottom line

The supplied reset found real 2026 infrastructure signals, but it did not perform an adequate corpus deduplication pass. Five of the seven retained concepts already exist in the repository at essentially the same layer:

| Supplied concept | Repository disposition |
|---|---|
| AgeGate Replay | Exact/near-exact duplicate of canonical `idea-309` AgeGate Chaos Lab and prior AgeProof Lab / EUDI Real-World Regression Cloud research. Merge the EU blueprint protocol matrix into `idea-309`; do not stage a new candidate. |
| SmallSoft Gate | Direct re-underwriting of canonical `idea-359` Small-Software Deployment Cloud. The security wrapper is a feature hypothesis, not a fresh idea. |
| MandateMesh | Duplicate of canonical `idea-341` EntityMandate and adjacent `idea-344` MandateCompiler. |
| NonFirm Replay | Overlaps the staged GridSlot concept and prior CurtailmentCost Replay. Modo Energy already supports uploaded time-varying curtailment profiles. Keep only a possible independent contract-review experiment. |
| TrustList Sentry | Duplicate of the prior TrustList Drift proposal; useful as a feature under AgeGate/EntityMandate. |
| FieldHandoff | Adjacent module for `idea-279` RobotOps and the staged Robot Skill Acceptance family. No workflow or buyer evidence was supplied. |
| CashCliff | Potentially distinct vertical framing, but supported by one anonymous anecdote and located in a crowded forecasting/construction-billing market. Research-only. |

The numerical scores are analyst opinions, not measurements. None has payment, customer-workflow, failure-artifact, or repeat-use evidence.

## Material factual corrections

- The Commission portal confirms seven front-runner Member States are piloting the age-verification solution in 2026 and that more participants are expected. It describes the pilot as occurring ahead of general availability; it does **not** state that full EU rollout will occur by the end of 2026.
- The official verifier documentation requires support for DC API and OID4VP presentation mechanisms and standard mdoc and ZKP proof types. Official reference components are incomplete/development tools, but that does not establish that every proposed 14-case chaos test is currently executable across national wallets.
- Regulation (EU) 2025/1569 applies Articles 6–9 from 19 August 2026 and requires Commission lists/catalogues in machine-readable and human-readable forms. The audit did not verify that every contemplated production feed and change event is already populated and operational.
- Commission Implementing Regulation (EU) 2026/1565 creates EUDR contingency reference numbers and declaration identifiers. Its 15 October 2026 deferred date applies only to Article 1(2)(c), which changes attribution of due-diligence statements to competent authorities—not to the contingency provisions.
- “90% of small apps remain on localhost” has no source and must not be used.
- CashCliff cannot truthfully promise an exact zero-cash date when payment timing is probabilistic. The defensible output is a scenario distribution and confidence range.

## What survives

The **Public Infrastructure Edge** is a useful search heuristic:

`free public core → private integration → production boundary → recurring interoperability/drift/reliability work`

It is not evidence of high willingness to pay by itself. The surviving action is two substitute-controlled payment experiments:

1. Update `idea-309` with the EU blueprint protocol/trust-list matrix and sell three authorized staging audits.
2. Re-underwrite `idea-359` by deploying customer-provided tiny apps while explicitly comparing Replit private deployments and Vercel, Cloudflare, and Modal sandboxes.

No canonical or staged idea count should increase because of RESET XX.
