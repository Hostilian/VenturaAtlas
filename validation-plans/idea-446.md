# Validation Plan — GPU Residual-Value Infrastructure

## Experiments

- **Most Important Uncertainty:** Will buyers treat the artifact as settlement-grade evidence?
- **Riskiest Assumption:** The underlying dispute or gap is frequent enough to matter.
- **Cheapest Test:** One fake-but-realistic example artifact.
- **Fastest Test:** Ask for a paid pilot or signed commitment.
- **Interview Plan:** Interview target buyers and recent case holders.

### Interview Questions
- What do you use today?
- Where do disputes happen?
- Who pays?
- What would make this untrustworthy?
- Would you pay for it?
- What would make you stop?

- **Landing Page Test:** Show the exact deliverable and ask for payment.
- **Smoke Test:** Offer the manual version before automating it.
- **Concierge Mvp:** Manually create the evidence object and review it with the buyer.
- **Wizard Of Oz:** Use a spreadsheet workflow behind a polished interface.
- **Prototype Test:** Compare outputs to buyer judgment.
- **Pricing Test:** Test at least two price points.
- **Demand Threshold:** 1-3 paid pilots or a repeat request.

### Success Criteria
- buyer trust
- paid pilot
- repeat request
- labor within budget

### Failure Criteria
- no buyer will pay
- problem occurs too rarely
- evidence is inaccessible
- support dominates price

### Evidence Before Build
- last-event interviews
- sample artifact
- payment signal
