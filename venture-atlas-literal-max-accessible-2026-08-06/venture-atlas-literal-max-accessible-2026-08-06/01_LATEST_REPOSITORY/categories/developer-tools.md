# Developer tools

8 ideas.

- [ProofRail — AI Work Acceptance Gate](../ideas/proofrail-ai-work-acceptance-gate.md) — Provider-neutral proof and acceptance between AI agents and merge/release.
- [Prompt Registry & Evaluation Lab](../ideas/prompt-registry-and-evaluation-lab.md) — Version, test, compare, and approve prompts with datasets and regressions.
- [Repository Autopilot](../ideas/repository-autopilot.md) — Continuously improve repositories through isolated, tested, evidence-backed changes.
- [Semantic Multi-Agent Merge Coordinator](../ideas/semantic-multi-agent-merge-coordinator.md) — Prevent parallel agents from creating conflicting or duplicated repository changes.
- [Release Evidence Ledger](../ideas/release-evidence-ledger.md) — Link requirements, diffs, tests, approvals, artifacts, and deployments immutably.
- [Mobile Release Factory](../ideas/mobile-release-factory.md) — Automate APK/IPA builds, screenshots, metadata, release notes, and rollout proof.
- [GitHub Pages Version Lab](../ideas/github-pages-version-lab.md) — Browse, compare, preserve, and validate many experimental product versions.
- [MCP Cross-Client Release Gate](../ideas/mcp-cross-client-release-gate.md) — Tests MCP servers across conformance, real clients, authentication paths, and protocol versions.
