# Adding an Idea

1. Add source inventory and exact raw mention.
2. Choose a stable `idea-NNN` ID and slug.
3. Preserve all variants and overlap notes.
4. Complete every required field or use `Unknown — requires validation`.
5. Add 25 scores with justification/confidence/basis.
6. Generate the dossier and 25 prompt files.
7. Recalculate rankings and relationships.
8. Run validation and review the completeness counts.
