Collaboration Room

The static site keeps local drafts in your browser; shared work happens through GitHub Issues and pull requests. Exported vote packets can be validated and committed without exposing browser tokens.

Modes

  1. Local/private: drafts, favorites, comparisons, and vote packets.
  2. Git-native: issue forms, PRs, evidence submissions, objections, and decisions.
  3. Optional backend: disabled by default.
