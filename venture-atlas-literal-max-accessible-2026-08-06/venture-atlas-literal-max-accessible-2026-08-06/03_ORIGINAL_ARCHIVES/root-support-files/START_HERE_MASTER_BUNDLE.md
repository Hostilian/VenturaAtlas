`work-vac/venture-atlas-collaborative/`

## Included material

- `venture-atlas-collaborative-v3.zip` — latest packaged collaborative repository.
- `venture-atlas-collaborative-v3.tar.gz` — latest TAR.GZ archive.
- `work-vac/venture-atlas-collaborative/` — fully extracted latest repository.
- `venture-atlas-os-v2.zip` and `.tar.gz` — complete previous v2 archives.
- `venture-atlas-os-v2/` — mounted v2 files available outside the archive.
- `venture-atlas-os.zip` and `.tar.gz` — earliest packaged repository archives.
- `venture-atlas-os/` — earliest mounted repository files.
- `Pasted markdown.md` — the uploaded collaborative master project prompt.
- `work-vac/upgrade.py` — repository upgrade/build script retained for provenance.
- `MASTER_BUNDLE_MANIFEST.csv` — file inventory with sizes and hashes.
- `MASTER_BUNDLE_SHA256SUMS.txt` — checksums for all files in this package before packaging.

Some content appears more than once intentionally: as an extracted repository and as its original ZIP/TAR archive. This preserves both easy browsing and exact historical packages.
