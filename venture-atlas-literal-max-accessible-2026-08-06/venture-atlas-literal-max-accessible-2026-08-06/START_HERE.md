# START HERE — Venture Atlas Maximum Accessible Corpus

This package is the largest honest bundle that could be created from the material accessible in the active ChatGPT workspace on 6 August 2026.

## What it includes

- The complete latest Venture Atlas Collaborative repository.
- All locally available previous repository versions.
- Every locally mounted ZIP, TAR.GZ, manifest, prompt, dataset, generated page, script, audit, and source file relevant to this project.
- The exact uploaded 3,025-line Master Project Prompt.
- A catalog of additional File Library sources discovered during the final recovery pass.
- Recovered source excerpts and provenance pointers for the original Deep Research execution contract, both August 2 research reports, and EUshop chat/log exports.
- A visible-project timeline, missing-source ledger, file manifest, and SHA-256 checksums.

## Critical truth

This is **not** a literal server-side export of every ChatGPT message from every historical conversation. ChatGPT did not expose the complete two-chat transcript as downloadable bytes in the active runtime. The archive contains every byte that was locally accessible plus a catalog of every additional source that could be located through File Library search.

The original Deep Research execution contract was located in File Library during this pass. Its file reference and recovered text are preserved under `04_FILE_LIBRARY_RECOVERY/`. The full original byte stream was still not mountable into the sandbox, so this bundle does not falsely claim a byte-identical copy of that remote file.
